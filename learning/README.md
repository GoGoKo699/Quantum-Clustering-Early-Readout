# Learning Quantum Clustering Early Readout

The educational anchor is John Watrous, *The Theory of Quantum Information* (2018), using the [author's standard-layout manuscript](https://jhwatrous.github.io/TQI.pdf). The [author's book page](https://jhwatrous.github.io/books-and-courses.html) identifies this version and its personal-use terms. This repository links to the book; it does not distribute a copy.

The learning route connects quantum states, instruments, state discrimination and symmetry to one specific question: which early classical records preserve the best possible final probability of recovering the entire binary cluster partition?

The model has native quantum inputs: each supplied specimen is one of two unknown independent Haar-pure prototypes, with independent uniform binary labels. Class names are interchangeable, and all measurement outcomes count. “Free” means exact preservation of the final Bayesian whole-partition score, while allowing the instrument to retain quantum output. It does not mean that the state is left unchanged.

Watrous supplies the quantum-information foundations. The harmonic subset-frame arguments, branching annihilator and exact temporal criterion are developed in the linked scientific pages. The [related-work account](../references/RELATED_WORK.md) distinguishes inherited clustering results from the project's additional claims.
